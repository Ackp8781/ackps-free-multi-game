# Ackp's Free Multi Game

Free browser games with no build step, hosted on GitHub Pages.

BlockCraft, the biggest game on the site, is a full voxel survival game built from scratch in `js/craft`: endless seeded terrain with biomes, caves and villages, Survival, Hardcore, Creative and Adventure modes, crafting, mobs, weather and online rooms. Every texture, model and sound is generated by code. It is an independent fan project, not affiliated with Mojang or Microsoft.

Accounts and saves live in each visitor's browser. Online rooms connect players directly with WebRTC through the public PeerJS service.
